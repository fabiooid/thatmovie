# Contributing to ThatMovie

The project is a local prototype and is licensed under the [MIT License](LICENSE).

- Keep the agent search-first. Do not add a path that names a film without calling `search-movies`.
- Do not invent movie titles in the agent instructions or in sample answers.
- Never commit credentials, the CMU Movie Summary Corpus, generated `data/movies.jsonl`, local databases, or traces.
- Keep `.env` and generated data out of git.
- Keep pull requests small and focused.
